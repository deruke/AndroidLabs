# Setup Burp Suite to Proxy and Interception Testing 
In this lab we will setup a connection between the virtual mobile device in Corellium and our MobileApp VM.

In order to ensure network traffic is routed from the virtual mobile device to our MobileApp VM, we first need to establish a VPN connection between the two hosts. More details on how to setup a VPN connection can be found [https://github.com/deruke/AndroidLabs/blob/main/Labs/Corellium_Setup/gettingstarted.md#VPN] [here].

## Open and Configure Burp
With a VPN connection established, return to your MobileApp VM and launch Burp Suite Community Edition by either running to following command or clicking on the Burp icon in the Favorites bar.
 
 - Option 1: Launch Burp via the command line.
  - `/home/mobileapp/BurpSuiteCommunity/BurpSuiteCommunity &`

 - Option 2: Launch Burp via the Favorites Tool Bar.
